ThinkRail documentation

The agentic IDE that gets better every time you use it.

What is ThinkRail?InstallChangelogGet help

ThinkRail is the open-source agentic IDE that gets better every time you use it. It is built around one agent, pi, and gives it a full IDE: isolated workspaces, diffs to review, and chats you can steer. ThinkRail is spec-first: your project’s intent lives in living specs that the agent reads and keeps current, so it builds on what it learned instead of relearning your project every session.

Main features

Section titled “Main features”
  • Spec-first. SPEC.md files and project goal specs sit beside your code as ground truth, and the agent maintains them as it works. See Living specs.
  • Parallel agents, isolated workspaces. Each task runs in its own git worktree and branch, so several agents work at once without touching your checkout. You review every diff before it ships. See Run agents in parallel and Review changes.
  • Provider-agnostic. Bring your own model: a Claude, ChatGPT, or GitHub Copilot subscription, JetBrains AI, or an API key for any provider pi supports. See Connect a model provider.
  • Open and extensible, built on pi. ThinkRail is Apache 2.0, and your pi skills, extensions, MCP servers, and prompt templates keep working. See ThinkRail and pi.

Quick start

Section titled “Quick start”

Install ThinkRail, connect a model, give the agent your project’s specs, and ship one reviewed change:

  1. Install ThinkRail — the desktop app or the thinkrail CLI.
  2. Connect a model provider — JetBrains AI, a subscription sign-in, or your own API keys.
  3. Describe your project — the agent drafts your project’s specs with the bundled setting-up-a-project skill.
  4. Make your first change — from an empty workspace to a pull request.
