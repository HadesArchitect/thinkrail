Reference

Settings reference

Open Settings from the gear in the top bar. The left navigation groups pages under Agent, Interface, and System, with a Get 100 credits for a user interview button at the bottom that opens the Feedback page. This page lists the pages in that order.

How to read the tables

Section titled “How to read the tables”

The Scope column says how far a setting reaches and where it is stored.

ScopeMeaning
Global (host)Saved on the host in ~/.thinkrail/config.json. It applies to every project and workspace on that host, and follows you across browsers and devices that connect to it.
Global (browser)Saved in this browser or desktop profile. It does not follow you to another browser, device, or host.
This window (browser)Saved in this browser or desktop profile for the current window only.
Global (pi)Saved in pi’s own files under ~/.pi, so the pi CLI sees it too.
ProjectApplies to one project.
WorkspaceApplies to one workspace and overrides the global value until you reset it.

Note

Some pages and options appear only when the host is new enough to support them. If a page described here is missing, the host is older than the app. Updates appears only when the app supplies update content: in the desktop app, and on a CLI host that can update itself.

Settings that change the model or the provider affect new chats. A chat that is already running keeps its model, effort, and context settings.

MCP servers

Section titled “MCP servers”

Part of Agent. Manage the Model Context Protocol servers available to chats in the active project. It needs an open workspace. A server runs on the host and inherits its environment.

ControlWhat it doesDefaultScope
Add a server / Import mcpServers JSONAdd a server from a form or by pasting JSON, as User — all projects or Project — .pi/mcp.json.No serversGlobal (pi) or Project
PresetsOne-click entries: Context7, DeepWiki, Linear (read-only), Sentry, Playwright.noneGlobal (pi) or Project
Row switch Enable <name> / Disable <name>Turn a server on or off. For a user-level server the switch applies to this project only.OnGlobal (pi) or Project
Exposure chipDeferred loads tools through tool search when needed, Direct declares them up front, Hidden registers them but keeps them out of reach.DeferredGlobal (pi) or Project
Row actionsSign in, Review & approve, Edit, Test connection, Reconnect, Reload now, Show log, Share with repo, Remove.noneSame as the server
Review & approveApprove a server a repository defines in .pi/mcp.json before chats can start it.Pending approvalProject

User servers live in ~/.pi/agent/mcp.json; project servers live in the repository’s .pi/mcp.json and load only when the project is trusted and each entry is approved. The file format, exposure modes, and call approvals are in MCP configuration and Connect MCP servers.

Privacy

Section titled “Privacy”

Part of System. Usage analytics.

OptionWhat it doesDefaultScope
Share additional usage dataShare setup, agent run, task completion, review, and pull-request outcome events, and how you found ThinkRail. Turning it off drops queued additional events. Basic events (launch, chat creation, message sends, provider connections) are not controlled by this switch. Hosts older than the additional-data consent show a Share anonymous usage analytics switch instead.Off until the first-run dialog; the dialog offers it onGlobal (host)

No prompts, code, files, credentials, or account identity are collected. The --no-analytics flag and THINKRAIL_NO_ANALYTICS variable turn the additional data off for one run without changing this saved choice. See Privacy and analytics and Turn off usage data (telemetry).

Updates

Section titled “Updates”

Part of System. Software updates. The page differs by how you run ThinkRail.

ControlWhat it doesApplies to
Check for UpdatesLook for a newer release. ThinkRail also checks in the background.Desktop app
DownloadDownload the available update. Downloads and installs start only when you choose them, and a download cannot be cancelled once started.Desktop app
Install & RestartInstall the downloaded update and restart. Closing Settings and quitting normally does not install it.Desktop app
Run UpdateRun thinkrail update on the host machine in the background, even when the UI is open in a browser on another machine. After it succeeds, restart the host yourself. Retry appears after a failure, along with the manual thinkrail update command.Installed CLI host
Version lineShows the current version and channel (stable or nightly), and the available version.Both

The desktop updater is enabled only for packaged stable and nightly builds whose package carries an update feed. A build that is not connected to an update channel shows Updates are unavailable. See Update and uninstall.

Feedback

Section titled “Feedback”

Opened from the Get 100 credits for a user interview button. It describes the product interview offer and has one button, Schedule an interview, which opens the booking page in a new tab. ThinkRail also shows an invitation dialog, Help shape ThinkRail, after your 10th accepted message; its counters are stored in ~/.thinkrail/feedback.json and do not depend on analytics.
